# Vyshivka.store 🧵✨

An artisanal, high-end e-commerce web application built for a custom embroidery brand. Designed with a luxury aesthetic, smooth interactive elements, and multi-channel ordering workflows.

## 🌟 Key Features
* **Bento-Grid Design Language:** A warm, neutral aesthetic featuring rich maroon accents (`#B5526B`) and a bespoke typography pairing (*Playfair Display* and *Montserrat*).
* **Interactive 3D UI Elements:** Global 3D tilt-card hover effects for product and story sections to elevate the luxury user experience.
* **Custom Shop Catalog:** Real-time filtered product catalog with interactive detail views and tailored product inquiry modals.
* **Multi-Channel Inquiry Workflows:** Seamless ordering and custom inquiry integration supporting **WhatsApp, Email, and Instagram** (including a custom clipboard-copy/toast notification workaround for Instagram direct parameters).
* **Order Tracking System:** Dedicated tracking page allowing customers to check the status of their handcrafted pieces.
* **Fully Responsive Architecture:** Fluid layout design optimized for mobile phones, tablets/iPads, and desktop displays with custom touch-safe floating element placements.

## 🛠️ Tech Stack
* **Markup & Structure:** HTML5
* **Styling:** CSS3 (Flexbox, CSS Grid, Custom Properties, Glassmorphism, Responsive Media Queries)
* **Interactivity:** Vanilla JavaScript (Real-time filtering, dynamic modal controls, clipboard handling)

## 📌 Project Description (For Portfolio / GitHub Bio)

> **Vyshivka.store** is a production-ready, artisanal e-commerce web application engineered to showcase luxury, custom-crafted embroidery. Designed with a sophisticated warm-neutral color palette and immersive Bento-grid layouts, the platform offers users an interactive catalog filter, a live price estimator, and multi-channel inquiry workflows connected directly to WhatsApp, Email, and Instagram. Built from scratch with clean HTML, modern CSS (featuring frosted-glass blur effects and 3D tilt cards), and vanilla JavaScript, the project delivers a seamless, high-performance shopping experience across all device viewports.
